# Ordinary Slayer and Deadeye

These classes use the extracted Default graph and ordinary saved class identities.
Their shared Game hooks follow the Inquisitor layer; they do not install a Phrecia graph.

## Native buff contracts

Tailwind row 1094 and Mark rows 74/77/78/80 are non-recovery buff definitions in client 3.29.3b.
Their AddBuff messages have no inline values list.
Appending one shifts the native read cursor; a negative Tailwind value was interpreted as an enormous
subsequent list count and hung the client.
Tailwind speed is projected through current player stats.
Qualified Mark values are projected on the exact target's Stats, with the original modifier baseline
restored when values change or the mark is removed.

Gale row 1095 has independent grant deadlines.
The native panel and authoritative action timing therefore need the same current remaining grant set.
Tailwind sharing currently uses nearby supported same-instance player presence because the server has no
party membership contract; this is not certified party behavior.

## Marks and detached actors

A completed pending Mark must be resolved before projectile split lookup, even before presentation runs.
Object identity and source qualification matter independently of the reused numeric target id.
Attack reconstruction for Mark effects retains the release-time Inquisitor Virtue factor.

Mirage uses `Metadata/Monsters/Mirage/RangerMirage` as a native one-Life owned actor.
The bounded native observer confirms the actor and autonomous target damage, but does not independently
observe every RemoveObject or certify attachment art, equipment or animation timing.
Detached actor lifetime validation is per captured skill/source signature; a different valid detached
skill must not retire another actor merely because its equipment signature differs.
Paid attack windups can survive newer owner actions, so their admission is carried by a per-use receipt
through scheduled release and impact.
Its once-only Mirage claim avoids retaining every past release in the area's session or reload payload.

## Remaining limits

Slayer's full shared leech cap, instant/ES/Mana recovery, bleed and DoT/proxy provenance matrix remains partial.
Deadeye's full native peer, equipment-removal, projectile inventory and finite Mark death-transfer timing
matrix remains partial, as does complete Ruthless coverage.
Bounded client controls do not establish whole-class or official-server parity.
